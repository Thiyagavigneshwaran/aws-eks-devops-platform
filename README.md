# Production-Style AWS EKS DevOps Platform

## Project Overview

This project aims to build and operate a production-style DevOps platform on AWS using Infrastructure as Code, Kubernetes, CI/CD, GitOps, monitoring and centralized logging.

## Objectives

- Provision AWS infrastructure using Terraform.
- Deploy and manage applications on Amazon EKS.
- Implement CI/CD using Jenkins.
- Implement GitOps using Argo CD.
- Containerize applications using Docker.
- Store container images in Amazon ECR.
- Monitor infrastructure and applications using Prometheus and Grafana.
- Implement centralized logging using Loki and Alloy.
- Automate server configuration using Ansible.
- Practise Kubernetes scaling, troubleshooting and failure recovery.
- Document architecture, implementation, costs and operational evidence.

## Application Architecture

- Frontend: React
- Backend: Node.js and Express
- Database: MySQL
- Background Processing: Worker service
